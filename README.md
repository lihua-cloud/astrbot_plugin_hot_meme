# 智能热梗响应插件（hot_meme）

为 [AstrBot](https://astrbot.app) 开发的智能热梗响应插件：自动识别并学习用户输入中的典型网络热梗与情绪性词汇（如「似冯」「串子」等），采用「关键词精准匹配 + 语境模糊匹配」相结合的方式，内置基础热梗回复库，并支持动态学习交互过程中出现的新热梗与回复风格。回复贴合对应热梗的网络语境，自然轻松，避免生硬机械。

## 功能特性

- **自动识别热梗**：识别「似冯」「串子」等流行情绪性、调侃类网络用语，内置 16+ 组基础热梗库。
- **精准 + 模糊双匹配**：关键词精准匹配（高置信度）+ 谐音/近义模糊匹配（结合语境词提升置信度），兼顾准确率与召回。
- **内置回复库 + 动态学习**：内置多样回复，命中后随机选取；支持命令学习新热梗，也支持从 `「」`/`“”` 包裹的新词中自动学习。
- **回应自然贴合语境**：每条热梗配备多条口语化回复，符合社群聊天的轻松调性。
- **丰富配置项**：热梗总开关、回复敏感度、模糊匹配开关、动态学习开关、自定义「热梗→回复」映射、白名单过滤。
- **遵循插件规范**：继承 `Star` 基类，实现 `initialize()` / `terminate()` 生命周期，支持热加载/热卸载，**无任何第三方依赖**（仅标准库 + AstrBot 自带的 API）。
- **防误判机制**：白名单过滤 + 每个热梗可配置「排除语境词」，例如消息出现「羊肉串/烤串」时不会误触发「串子」。

## 安装方式

1. 将 `hot_meme` 文件夹放入 AstrBot 的插件目录：`AstrBot/data/plugins/`。
2. 重启 AstrBot（或在 WebUI 的「插件管理」中点击重载）。
3. 在 WebUI「插件」页面找到「智能热梗响应」，按需调整配置后保存。

> 无需安装任何第三方依赖。插件使用标准库与 AstrBot 自带的插件 API 与 KV 存储。

## 配置说明

在 WebUI 插件配置面板（或直接编辑生成于 `AstrBot/data/config/hot_meme_config.json` 的配置）可调整：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | true | 热梗响应总开关 |
| `sensitivity` | int | 45 | 回复敏感度（0-100）。数值越大越宽松，越容易触发模糊匹配；100 时仅精准匹配；0 时最严格 |
| `fuzzy_enabled` | bool | true | 是否启用语境模糊匹配（谐音/近义 + 语境词） |
| `learn_enabled` | bool | true | 是否允许动态学习新热梗 |
| `custom_mappings` | dict | {} | 自定义「热梗 → 回复」映射：键为热梗词，值为回复文本或回复列表 |
| `whitelist` | list | [] | 白名单过滤：消息中出现这些词时跳过热梗响应，避免误判 |

### 敏感度与匹配置信度

匹配引擎为每种命中计算置信度：

- 精准关键词命中：置信度 **100**
- 模糊匹配且命中语境词：置信度 **80**
- 模糊匹配但无语境词：置信度 **50**

只有 `命中置信度 >= sensitivity` 时才会回复。因此：

- `sensitivity = 0`：最严格，仅精准匹配触发（`100 >= 0` 恒成立，但模糊 `50/80` 也会触发，实际如需「仅精准」请把 `fuzzy_enabled` 设为 false）。
- `sensitivity = 45`（默认）：精准与带语境模糊均可触发，无语境模糊不触发。
- `sensitivity = 100`：仅精准匹配触发。

> 提示：想彻底关闭模糊匹配，优先把 `fuzzy_enabled` 设为 false。

## 使用示例

### 1. 自动响应热梗

用户（群聊或私聊）直接输入包含热梗的消息即可触发，无需 @ 或唤醒词：

```
用户：你这就很似冯了
机器人：你别说，还真有点似冯内味儿了。

用户：主播这波太抽象，似风啊
机器人：冯子虽无，其神常在，抽象就完事了。

用户：他直接破防了
机器人：这波直接破防了属于是。

用户：yyds
机器人：yyds！
```

### 2. 学习新热梗（管理员）

```
/hotmeme learn 尊嘟 尊嘟~|尊嘟假嘟
# 机器人：已学习热梗「尊嘟」，共 2 条回复。

用户：真的吗尊嘟
机器人：尊嘟假嘟？尊嘟。
```

### 3. 删除热梗（管理员）

```
/hotmeme forget 尊嘟
# 机器人：已删除热梗「尊嘟」。
```

### 4. 查看热梗

```
/hotmeme list
# 内置热梗词 N 个，已学习热梗 M 个。
# · 尊嘟（2 条回复）
```

### 5. 临时开/关与敏感度（管理员）

```
/hotmeme off      # 关闭热梗响应
/hotmeme on       # 开启热梗响应
/hotmeme sens 60  # 调整敏感度
```

### 6. 帮助

```
/hotmeme help
```

> 管理员身份由 AstrBot 的 `admins_id` 判断（可用 `/sid` 获取 ID）。

## 热梗扩展方法

### 方式一：命令学习（推荐，运行时动态扩展）

对管理员执行：

```
/hotmeme learn 关键词 回复1|回复2|回复3
```

例如：

```
/hotmeme learn 典 典中典|太典了
```

同一关键词可给出多条回复，命中时随机选取一条，保证回复不单调。

### 方式二：自动学习（从引号包裹的新词）

开启 `learn_enabled` 后，插件会跟踪用户消息中 `「」`、`『』`、`“”` 包裹的短词；同一新词出现 3 次后自动学习为热梗（回复为通用探语）。例如用户多次发送 `「蚌」`，插件会记入热梗库。

### 方式三：配置面板自定义映射

在 WebUI「自定义热梗映射」中编辑 JSON/键值对（`热梗词 → 回复`）：

```json
{
  "蚌": "蚌埠住了",
  "乖乖": ["乖乖", "这波太乖了"]
}
```

自定义映射的回复会合并进对应热梗；若对应词是内置热梗的关键词，则在原有回复上追加。

### 方式四：修改内置热梗库（代码级扩展）

编辑 `main.py` 中的 `BASE_MEMES` 字典，按下列结构新增条目：

```python
BASE_MEMES = {
    "xingan": {
        "keywords": ["新梗词"],       # 精准匹配关键词
        "fuzzy": ["谐音变体"],         # 模糊匹配（谐音/近义）
        "context": ["语境词"],         # 出现则提升模糊匹配置信度
        "negative": ["排除词"],        # 出现则本次命中作废（防误判）
        "replies": ["回复一", "回复二"], # 回复候选
    },
}
```

- `keywords`：精准触发词，命中置信度 100。
- `fuzzy`：模糊触发词（谐音、变体），命中置信度 50；若同时出现 `context` 中的词则升到 80。
- `context`：语境词列表，用于辅助模糊匹配，减少对普通场景的误判。
- `negative`：排除语境词，出现在关键词附近（约 4 字窗口）时作废本次命中。例如「串子」配置 `negative: ["羊肉串", "烤串"]`，避免聊天提到烧烤时误触发。
- `replies`：回复候选列表。

修改后重启/重载插件即可生效。

## 防误判机制说明

1. **白名单过滤**（`whitelist`）：消息中出现白名单词时整体跳过，适合屏蔽某些高频且易混淆的场景。
2. **排除语境词**（`negative`）：每个热梗可配排除语境词，靠近关键词时作废命中。
3. **置信度阈值**（`sensitivity`）：只有达到敏感度的命中才回复，模糊匹配需更高把握。
4. **模糊开关**（`fuzzy_enabled`）：可整体关闭模糊匹配，仅保留精准匹配。

## 常见问题

**Q：为什么群里发「羊肉串子」没反应？**
A：因为「串子」的热梗被 `羊肉串` 等排除语境词命中，属于防误判，符合预期。

**Q：学习的数据存在哪里？**
A：通过 AstrBot 的插件 KV 存储持久化（随 AstrBot 数据目录），重载/重启后自动恢复，无需额外文件或数据库。

**Q：能适配多个平台吗？**
A：插件仅依赖 AstrBot 统一消息事件接口，理论上适配 AstrBot 支持的各类平台（aiocqhttp、QQ 官方等），不对特定平台做额外绑定。
